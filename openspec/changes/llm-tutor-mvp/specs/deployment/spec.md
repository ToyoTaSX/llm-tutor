# Spec Delta

## Purpose

Описывает, как систему запускают на локальном ПК: все компоненты в контейнерах поднимаются одной командой, используют GPU и локальные модели, настройки задаются в одном файле.

## ADDED Requirements

### Requirement: Запуск одной командой
Система SHALL запускаться целиком (веб-интерфейс, сервер приложения, сервер языковой модели, векторная база) одной командой `docker compose up` из корня проекта. Веб-интерфейс открывается в браузере по адресу `http://localhost:3000`.

#### Scenario: Первый запуск
- **WHEN** пользователь заполнил `.env` по образцу `.env.example`, положил модели в указанную папку и выполнил `docker compose up`
- **THEN** после старта всех сервисов по адресу `http://localhost:3000` открывается страница входа

#### Scenario: Порядок готовности
- **WHEN** сервер языковой модели ещё загружает модель
- **THEN** сервер приложения дожидается его готовности, а интерфейс до этого не принимает вопросы и сообщает, что модель загружается

### Requirement: Конфигурация через .env
Система SHALL брать все настраиваемые параметры из файла `.env`: список логинов лекторов, секрет сессий, пути к моделям, параметры поиска и генерации, порты. В репозитории есть `.env.example` с описанием каждого параметра и рабочими значениями по умолчанию.

#### Scenario: Отсутствует обязательный параметр
- **WHEN** в `.env` не задан секрет сессий
- **THEN** сервер приложения не стартует и выводит в лог, какой параметр нужно задать

### Requirement: Локальные модели без интернета
Система SHALL использовать модели с диска хоста: языковую модель в формате GGUF (по умолчанию Qwen2.5-3B-Instruct Q4_K_M) и модель эмбеддингов BGE-M3. Скачивание моделей во время работы не требуется.

#### Scenario: Работа без сети
- **WHEN** модели лежат в папке, указанной в `.env`, а доступа в интернет нет
- **THEN** система запускается и отвечает на вопросы

#### Scenario: Модель не найдена
- **WHEN** файла модели по указанному пути нет
- **THEN** соответствующий сервис завершается с сообщением, какой файл ожидался

### Requirement: Использование GPU
Система SHALL выполнять языковую модель и модель эмбеддингов на видеокарте NVIDIA хоста (целевая — RTX 5060 Ti 16 ГБ) через Docker Desktop с WSL2.

#### Scenario: GPU доступен
- **WHEN** система запущена на целевом ПК
- **THEN** логи сервисов подтверждают, что модели загружены на GPU

### Requirement: Сохранение данных между перезапусками
Система SHALL хранить учётные записи, журнал, документы и поисковый индекс в томах Docker, чтобы они сохранялись при `docker compose down` и повторном `up`.

#### Scenario: Перезапуск
- **WHEN** пользователь выполнил `docker compose down`, затем `docker compose up`
- **THEN** учётные записи, загруженные лекции, индекс и журнал на месте, повторная индексация не нужна
