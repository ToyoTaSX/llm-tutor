# Spec Delta

## Purpose

Даёт лектору пополнять и поддерживать базу лекций, по которой отвечает ассистент: загружать текстовые документы, индексировать их, удалять и переиндексировать.

## ADDED Requirements

### Requirement: Загрузка текстовой лекции
Система SHALL позволять лектору загрузить один или несколько файлов `.txt` (до 10 МБ каждый) в кодировке UTF-8 (с BOM или без) или Windows-1251. Название документа по умолчанию берётся из имени файла, лектор может его изменить.

#### Scenario: Успешная загрузка
- **WHEN** лектор перетаскивает файл `Лекция 13.txt` в UTF-8
- **THEN** в списке документов появляется «Лекция 13» со статусом «индексируется»

#### Scenario: Файл в Windows-1251
- **WHEN** лектор загружает лекцию, сохранённую в Windows-1251
- **THEN** текст корректно распознаётся, а фрагменты в источниках читаются без искажений

#### Scenario: Неподдерживаемый файл
- **WHEN** лектор загружает `.pdf`, файл больше 10 МБ, пустой файл или файл в нераспознаваемой кодировке
- **THEN** система отклоняет его с понятной причиной и не создаёт документ

### Requirement: Фоновая индексация
Система SHALL индексировать загруженный документ в фоне: нарезать на фрагменты, вычислять векторы и добавлять их в поисковый индекс, не трогая остальные документы. Во время индексации система продолжает отвечать на вопросы.

#### Scenario: Документ становится доступен для поиска
- **WHEN** индексация документа завершилась
- **THEN** его статус меняется на «готов», указывается число фрагментов, и его фрагменты участвуют в ответах

#### Scenario: Остальные документы не затрагиваются
- **WHEN** индексируется новый документ
- **THEN** ранее проиндексированные документы остаются доступными для поиска без перерыва

#### Scenario: Ошибка индексации
- **WHEN** индексация завершилась сбоем
- **THEN** документ получает статус «ошибка» с текстом причины, а частично добавленные фрагменты удаляются из индекса

### Requirement: Нарезка на фрагменты
Система SHALL делить текст на фрагменты заданного размера (по умолчанию до 1000 символов) по границам предложений, с перекрытием соседних фрагментов (по умолчанию около 200 символов). Фрагмент не пересекает заголовок главы или раздела.

#### Scenario: Граница главы
- **WHEN** в тексте есть строка-заголовок `ГЛАВА 02 · ...`
- **THEN** ни один фрагмент не содержит одновременно текст до и после этого заголовка

#### Scenario: Очень длинное предложение
- **WHEN** предложение длиннее максимального размера фрагмента
- **THEN** оно режется по словам, и каждая часть не превышает максимальный размер

### Requirement: Список документов
Система SHALL показывать лектору список документов с названием, именем файла, статусом (индексируется / готов / ошибка), числом фрагментов, размером в символах, автором загрузки и датой. Статус обновляется без перезагрузки страницы.

#### Scenario: Отслеживание индексации
- **WHEN** лектор загрузил документ и остаётся на странице «Документы»
- **THEN** статус документа сменяется на «готов» без ручного обновления страницы

### Requirement: Удаление документа
Система SHALL позволять лектору удалить документ после подтверждения. Вместе с документом из поискового индекса удаляются все его фрагменты. Записи журнала, ссылающиеся на документ, сохраняются.

#### Scenario: Удаление
- **WHEN** лектор удаляет «Лекция 13» и подтверждает действие
- **THEN** документ исчезает из списка, и его фрагменты больше не находятся поиском

#### Scenario: История остаётся читаемой
- **WHEN** документ удалён, а в журнале есть ответ со ссылкой на его фрагмент
- **THEN** в журнале сохраняются сохранённые текст и название фрагмента

### Requirement: Переиндексация документа
Система SHALL позволять лектору переиндексировать документ, например после изменения параметров нарезки или после ошибки. Старые фрагменты документа заменяются новыми.

#### Scenario: Повтор после ошибки
- **WHEN** лектор нажимает «Переиндексировать» у документа со статусом «ошибка»
- **THEN** документ снова проходит индексацию, и при успехе получает статус «готов»

### Requirement: Демо-корпус при первом запуске
Система SHALL при первом запуске с пустой базой документов автоматически загрузить и проиндексировать демо-корпус лекций курса (`course.txt`), если он доступен.

#### Scenario: Первый запуск
- **WHEN** система запускается впервые, а база документов пуста
- **THEN** в списке документов появляется демо-корпус, и после индексации на вопросы по курсу можно получить ответы

#### Scenario: Повторный запуск
- **WHEN** система перезапускается, а демо-корпус уже загружался раньше (даже если лектор его потом удалил)
- **THEN** демо-корпус повторно не добавляется
