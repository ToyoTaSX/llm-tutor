# Spec Delta

## Purpose

Отвечает на вопросы пользователей по содержанию проиндексированных лекций. Показывает фрагменты, на которых основан ответ, и собирает оценку качества ответа.

## ADDED Requirements

### Requirement: Ответ на вопрос по лекциям
Система SHALL принимать от авторизованного пользователя вопрос (непустой, до 2000 символов) и формировать ответ локальной языковой моделью только по найденным фрагментам лекций. Каждый вопрос обрабатывается независимо, без контекста предыдущих вопросов.

#### Scenario: Вопрос по теме курса
- **WHEN** студент спрашивает «Что такое токен?», а тема есть в проиндексированных лекциях
- **THEN** система возвращает ответ на русском языке, основанный на фрагментах лекций, со ссылками на них в виде `[n]`

#### Scenario: Вопрос вне курса
- **WHEN** студент задаёт вопрос, по которому в лекциях нет подходящих фрагментов
- **THEN** система отвечает «Эта тема в курсе не разбиралась» и не придумывает ответ из общих знаний

#### Scenario: Пустой вопрос
- **WHEN** пользователь отправляет пустой вопрос или вопрос длиннее 2000 символов
- **THEN** система отклоняет его без обращения к модели

#### Scenario: Нет проиндексированных документов
- **WHEN** пользователь задаёт вопрос, а в базе нет ни одного готового документа
- **THEN** система сообщает, что лекции ещё не загружены

### Requirement: Гибридный поиск фрагментов
Система SHALL находить фрагменты для ответа комбинацией смыслового (плотные векторы) и лексического (разреженные векторы) поиска со слиянием рангов. Модели передаются первые 6 фрагментов (настраивается) из всех документов в статусе «готов».

#### Scenario: Точный термин
- **WHEN** вопрос содержит редкий термин, дословно встречающийся в одной лекции
- **THEN** фрагмент с этим термином входит в число переданных модели

#### Scenario: Удалённые документы не используются
- **WHEN** лектор удалил документ
- **THEN** его фрагменты больше не попадают в ответы

### Requirement: Потоковая выдача ответа
Система SHALL выдавать ответ по мере генерации, чтобы текст появлялся в интерфейсе постепенно. Список найденных источников передаётся до начала текста ответа.

#### Scenario: Постепенное появление ответа
- **WHEN** пользователь отправил вопрос
- **THEN** панель источников заполняется до появления первого слова ответа, а затем текст ответа дописывается по частям

#### Scenario: Сбой модели во время ответа
- **WHEN** языковая модель недоступна или генерация прервалась
- **THEN** пользователь видит понятное сообщение об ошибке, а поле ввода снова становится доступным

### Requirement: Панель источников
Система SHALL показывать рядом с ответом панель источников. Для каждого фрагмента в ней указаны номер `[n]`, название документа, номер фрагмента, относительная релевантность и начало текста; полный текст раскрывается по запросу. Панель можно свернуть.

#### Scenario: Раскрытие фрагмента
- **WHEN** пользователь нажимает на карточку источника
- **THEN** отображается полный текст фрагмента

#### Scenario: Сворачивание панели
- **WHEN** пользователь сворачивает панель источников
- **THEN** область ответа расширяется, а при следующем вопросе панель остаётся свёрнутой

### Requirement: Связь ссылок в ответе с источниками
Система SHALL делать ссылки `[n]` в тексте ответа интерактивными и визуально отличать фрагменты, на которые ответ ссылается, от найденных, но не процитированных.

#### Scenario: Переход по ссылке
- **WHEN** пользователь нажимает на `[3]` в тексте ответа
- **THEN** панель источников прокручивается к фрагменту №3 и подсвечивает его

#### Scenario: Непроцитированные фрагменты
- **WHEN** ответ ссылается только на `[1]` и `[3]`, а найдено 6 фрагментов
- **THEN** фрагменты 2, 4, 5, 6 отображаются приглушённо

### Requirement: Оценка ответа
Система SHALL позволять автору вопроса оценить завершённый ответ по шкале от 1 до 5 звёзд и сохранять оценку в журнале. Оценку можно изменить, хранится последняя.

#### Scenario: Студент ставит оценку
- **WHEN** ответ завершён и студент выбирает 4 звезды
- **THEN** оценка 4 сохраняется для этого вопроса и отображается как выставленная

#### Scenario: Изменение оценки
- **WHEN** студент поставил 2 звезды, а затем выбрал 5
- **THEN** в журнале для этого вопроса хранится оценка 5

#### Scenario: Оценка чужого ответа
- **WHEN** пользователь пытается оценить ответ на вопрос другого пользователя
- **THEN** система отклоняет запрос

#### Scenario: Недопустимое значение
- **WHEN** приходит оценка 0 или 6
- **THEN** система отклоняет её

#### Scenario: Ответ с ошибкой
- **WHEN** генерация ответа завершилась ошибкой
- **THEN** элемент оценки для этого ответа не показывается

### Requirement: История своих вопросов
Система SHALL показывать пользователю список его прошлых вопросов (новые сверху) и по выбору открывать вопрос с ответом, источниками и выставленной оценкой. Пользователь видит только свои вопросы.

#### Scenario: Открытие прошлого вопроса
- **WHEN** студент выбирает вопрос в истории
- **THEN** отображаются сохранённые вопрос, ответ, те же источники и оценка, а если оценки нет, её можно поставить

#### Scenario: Изоляция истории
- **WHEN** два студента пользуются системой
- **THEN** каждый видит в истории только свои вопросы
