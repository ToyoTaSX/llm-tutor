# Spec Delta

## MODIFIED Requirements

### Requirement: Конфигурация через .env
Система SHALL брать все настраиваемые параметры из файла `.env`: список логинов лекторов, секрет сессий, пути к моделям, параметры поиска и генерации, порты, адрес MCP-сервера поиска и его параметры, а также API-ключ поиска (переменная `TAVILY_API_KEY`). В репозитории есть `.env.example` с описанием каждого параметра и рабочими значениями по умолчанию; значение API-ключа в нём пустое.

#### Scenario: Отсутствует обязательный параметр
- **WHEN** в `.env` не задан секрет сессий
- **THEN** сервер приложения не стартует и выводит в лог, какой параметр нужно задать

#### Scenario: Не задан ключ поиска
- **WHEN** в `.env` нет `TAVILY_API_KEY`
- **THEN** сервер приложения стартует, режим «Только курс» работает, а веб-поиск выполняется без ключа или завершается статусом `error`

### Requirement: Локальные модели без интернета
Система SHALL использовать модели с диска хоста: языковую модель в формате GGUF (по умолчанию Qwen2.5-3B-Instruct Q4_K_M) и модель эмбеддингов BGE-M3. Скачивание моделей во время работы не требуется. Доступ в интернет нужен только режиму «Курс + интернет» для обращения к MCP-серверу поиска.

#### Scenario: Работа без сети
- **WHEN** модели лежат в папке, указанной в `.env`, а доступа в интернет нет
- **THEN** система запускается и отвечает на вопросы в режиме «Только курс», а в режиме «Курс + интернет» отвечает по лекциям с сообщением «Интернет-поиск временно недоступен»

#### Scenario: Модель не найдена
- **WHEN** файла модели по указанному пути нет
- **THEN** соответствующий сервис завершается с сообщением, какой файл ожидался
