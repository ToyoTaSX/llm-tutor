# Spec Delta

## Purpose

Даёт воспроизводимый способ сравнить конфигурации ассистента. Контрольный набор вопросов прогоняется через тот же код поиска и генерации, что и приложение, а результаты выгружаются для ручной разметки точности, ссылок и времени.

## ADDED Requirements

### Requirement: Прогон контрольного набора в выбранном режиме
Система SHALL предоставлять команду, которая прогоняет все вопросы из CSV-файла в указанном режиме («Только курс» или «Курс + интернет») с теми же настройками модели и поиска, что у приложения. Результаты сохраняются в CSV (UTF-8 с BOM, разделитель «;»).

#### Scenario: Прогон в двух режимах
- **WHEN** оператор запускает прогон набора из 12 вопросов сначала в режиме «Только курс», затем в режиме «Курс + интернет»
- **THEN** появляются два CSV-файла по 12 строк, в имени или содержимом каждого указан режим

#### Scenario: Недоступный веб-поиск при прогоне
- **WHEN** прогон в режиме «Курс + интернет» идёт без доступа в интернет
- **THEN** прогон не прерывается, у каждого вопроса записан статус поиска `error` или `timeout`, а ответ построен по лекциям

### Requirement: Колонки для ручной разметки
Система SHALL записывать для каждого вопроса: id, тип, вопрос, эталон, допустимые источники, дату проверки, режим, ответ, использованные фрагменты лекций, веб-источники (URL), статус и время MCP, время поиска по лекциям, генерации и полное время, а также пустые колонки `correct` (0, 0.5 или 1), `citation_ok` (0 или 1) и `abstained` (для вопросов типа `trap`).

#### Scenario: Разметка в Excel
- **WHEN** оператор открывает результат прогона в Excel
- **THEN** он видит все перечисленные колонки, а колонки разметки пусты и готовы к заполнению

### Requirement: Контрольный набор для веб-режима
Система SHALL содержать контрольный набор из 12 вопросов: 4 типа `course` (ответ есть в лекциях), 4 типа `web` (темы нет в лекциях, есть проверяемый ответ на надёжном сайте), 2 типа `multi` (нужно сопоставить два источника) и 2 типа `trap` (надёжного ответа нет или ложная предпосылка). Для каждого вопроса заданы эталон, допустимые источники или домены и дата проверки. Срочные новости в набор не входят.

#### Scenario: Состав набора
- **WHEN** набор загружается для прогона
- **THEN** в нём ровно 12 вопросов с типами в пропорции 4/4/2/2, и у каждого заполнены эталон, допустимые источники и дата проверки

### Requirement: Сводка по прогону
Система SHALL после прогона выводить сводку: среднее полное время ответа, среднее время MCP (для режима «Курс + интернет»), распределение статусов MCP и, если колонки разметки уже заполнены, точность всего и по типам, долю `citation_ok = 1` и число пройденных ловушек.

#### Scenario: Сводка по размеченному файлу
- **WHEN** оператор запускает подсчёт сводки по CSV с заполненными колонками `correct`, `citation_ok` и `abstained`
- **THEN** выводятся показатели для строки сравнительной таблицы лабораторной: точность всего, `course`, `web`, ловушки, доля корректных ссылок, среднее время MCP и полное время

### Requirement: Без нагрузочного теста внешнего поиска
Система MUST выполнять прогон контрольного набора последовательно, без параллельной нагрузки на внешний поисковый сервис.

#### Scenario: Последовательные вызовы
- **WHEN** выполняется прогон в режиме «Курс + интернет»
- **THEN** в каждый момент времени к MCP-серверу выполняется не более одного запроса
