# Spec Delta

## MODIFIED Requirements

### Requirement: Журнал вопросов и ответов
Система SHALL сохранять каждый обработанный вопрос в отдельном журнале. Запись содержит дату и время, пользователя, режим ответа, вопрос, ответ, оценку (пока не выставлена — пусто), список фрагментов лекций с текстом и названием документа, время поиска и генерации, полное время ответа, число токенов и признак «тема не разбиралась». Для режима «Курс + интернет» запись также содержит отправленный поисковый запрос, список полученных веб-источников с URL, статус MCP-поиска (`ok`, `empty`, `timeout`, `error`) и его длительность.

#### Scenario: Запись после ответа
- **WHEN** студент получил ответ на вопрос
- **THEN** в журнале появляется запись с датой, его логином, режимом, вопросом, ответом, источниками и пустой оценкой

#### Scenario: Запись веб-режима
- **WHEN** студент получил ответ в режиме «Курс + интернет»
- **THEN** запись журнала содержит поисковый запрос, полученные URL, статус MCP, длительность MCP-запроса и полное время ответа

#### Scenario: Сбой веб-поиска
- **WHEN** веб-поиск завершился тайм-аутом, а ответ построен по лекциям
- **THEN** запись сохраняется как успешный ответ со статусом MCP `timeout` и пустым списком URL

#### Scenario: Оценка попадает в журнал
- **WHEN** студент оценил ответ в 5 звёзд
- **THEN** запись журнала для этого вопроса содержит оценку 5 и время её выставления

#### Scenario: Ответ «тема не разбиралась»
- **WHEN** ассистент в режиме «Только курс» ответил, что тема в курсе не разбиралась
- **THEN** запись журнала отмечена признаком «нет ответа»

#### Scenario: Ошибка генерации
- **WHEN** ответ не был получен из-за ошибки модели
- **THEN** запись сохраняется с отметкой об ошибке и не учитывается в средней оценке

### Requirement: Просмотр журнала лектором
Система SHALL показывать лектору последние записи журнала (новые сверху, постранично) с датой, логином, режимом, вопросом, началом ответа и оценкой. Доступны фильтры «оценка ≤ 2», «без оценки» и «тема не разбиралась», фильтр по режиму («Только курс» / «Курс + интернет») и поиск по тексту вопроса.

#### Scenario: Разбор плохих ответов
- **WHEN** лектор включает фильтр «оценка ≤ 2»
- **THEN** в списке остаются только записи с оценкой 1 или 2

#### Scenario: Фильтр по режиму
- **WHEN** лектор выбирает режим «Курс + интернет»
- **THEN** в списке остаются только записи, полученные в этом режиме; фильтр по режиму сочетается с остальными фильтрами и поиском

#### Scenario: Детали записи
- **WHEN** лектор открывает запись журнала
- **THEN** он видит полный вопрос, полный ответ, оценку и сохранённые источники в том же виде, что и в панели источников студента, а для веб-режима ещё поисковый запрос, список URL, статус MCP, длительность MCP и полное время ответа

#### Scenario: Поиск по вопросам
- **WHEN** лектор вводит в поиск «трансформер»
- **THEN** в списке остаются записи, в тексте вопроса которых есть это слово
